# XXD Panel 048｜透明结构蓝图生产提示词

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、外轮廓、比例、姿态、方向、动作、功能、空间关系、材质与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

把可识别主体重构为介于工程图纸、X-ray 透视、科学图解与未来档案之间的透明结构蓝图。保持外轮廓一眼可辨，并根据对象本身决定“内部”如何解释：器物展示组件与连接，建筑展示空间与构造，交通工具展示动力与承载，植物展示枝脉与生长，人物或动物展示姿态骨架、动作轨迹或服装层次；绝不进行血肉化解剖，也不凭空机械化。

严格遵循：锁定身份、轮廓、姿态与叙事关系 → 保留三个线索 → 决定该主体真正有意义的内部结构 → 选择性显露半透明层、剖切面与连接 → 用局部放大、爆炸分解、轴线、尺寸线、节点和引线组织唯一阅读路径 → 从源图提取一个清透明亮的单色体系 → 保持大量干净留白 → 让技术文案精确绑定对应结构。

## 硬性视觉要求

- 主体外轮廓、比例、方向与关键关系必须清晰可辨；内部逻辑必须属于该对象，而非通用零件堆积。
- 半透明、剖切、分层显影、透视、局部放大和爆炸分解只用于解释重要结构；以线宽、透明度、虚实和疏密区分信息层级。
- 细轴线、尺寸线、节点编号、框选、小型结构示意和引线围绕主体展开，不得变成满版科技 UI。
- 一幅只保留一个视觉中心和清晰阅读路径，保持宽裕留白；不得普通线稿化、CAD 截图化或廉价 HUD 化。
- 从源图最具辨识度与精气神的颜色提炼浅色背景、一个主线色和少量明暗层级；颜色可以是蓝、绿、红、橙、紫或中性，不得固定蓝色，不得脏灰、暗沉、霓虹或复杂多色。

## 文案与语言

服从已确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。自动文案从主体身份、功能、状态、动作或象征含义中提炼简短标题，只添加必要的部件名、状态词、方向、尺度、编号或微注释。每段文字必须通过真实引线、标尺、节点、切面或边缘与主体建立精确关系；不使用年份，不写大段说明。准确文案逐字保留；无文字模式不得出现任何字符、数字、标签或伪文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计和壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果。连贯套装始终共同参考原照片与同一张批准定调图，绝不串联衍生图。

拒绝：普通轮廓线稿、通用蓝图、固定蓝色、任意机械零件、血肉化解剖、复杂科技 UI、满版标注、霓虹赛博、多色仪表盘、不可读伪技术文字、logo、水印、色卡、设备样机与无依据事实。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
