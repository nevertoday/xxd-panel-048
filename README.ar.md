يعيد XXD Panel 048 بناء الموضوع القابل للتعرّف كمخطط بنيوي بين الرسم الهندسي، والشفافية بالأشعة، والرسم العلمي، والأرشيف المستقبلي. ويُفسَّر الداخل وفق طبيعة الموضوع، لا بإضافة أجزاء آلية عامة.

## الدافع الجمالي

يُثبَّت المحيط والوضع والعلاقة، وتُحفظ ثلاث علامات خاصة بالمصدر على الأقل. لا تظهر إلا البنية الداخلية ذات المعنى عبر الشفافية والمقاطع، ثم تنظم المحاور والأبعاد والعقد وخطوط الإشارة مسار قراءة واحداً. تُستخدم أرضية فاتحة ولون خط رئيسي مشتق من المصدر وفراغات واسعة؛ ولا يكون الأزرق افتراضياً. تُرفض الخطوط العادية، والتشريح الدموي، والميكنة الاعتباطية، وواجهات HUD المكتظة، والنص التقني الزائف.

## أربعة أنماط قابلة للجمع

- `top-bottom`: متكيف مع المصدر `W×2H`، تقسيم 50/50 دقيق.
- `left-right`: متكيف مع المصدر `2W×H`، تقسيم 50/50 دقيق.
- `design-only`: متكيف مع المصدر `W×H`، التصميم المتحوّل فقط.
- `wallpaper-pack`: ملفات PNG منفصلة للهاتف وiPad والحاسوب وساعة الأطفال.

يمكن اختيار نمط واحد أو أكثر، والخلفيات مترابطة أو مستقلة. قبل التوليد يُحسم النص التلقائي أو النص الدقيق أو غياب النص، وتُحدد اللغة／المنطقة المستهدفة. تحفظ النتائج بصيغة PNG داخل مهمة جديدة في `~/Desktop/xxd/xxd-panel-048/<fresh-task>/`.
